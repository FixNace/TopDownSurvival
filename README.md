# 🎮 Программный модуль «TOPDOWN» / 2D Top-Down Shooter

![Unity](https://img.shields.io/badge/Unity-2022.3%20LTS-blue?logo=unity)
![Language](https://img.shields.io/badge/Language-C%23-green?logo=c-sharp)
![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20PC-orange)

Репозиторий содержит исходный код и ассеты для мобильного 2D-шутера с видом сверху, разработанного в рамках курсового проекта. Игра обладает полноценным геймплейным циклом: от динамического выбора героев и прогрессии по уровням до тактических сражений с волнами противников и прокачки в магазине.

---

## 🚀 Ключевые особенности и механики

### 1. Система игровых классов (Meta-Progression)
В игре реализован выбор между тремя уникальными персонажами, каждый из которых кардинально меняет игровой процесс за счет своих стартовых характеристик и пассивных/активных умений:

| Класс | Здоровье (HP) | Скорость | Особые свойства / Способности |
| :--- | :---: | :---: | :--- |
| **Танк** | 500 | 4 | Активная способность: Щит. Пассивный шанс блока урона: 30%. |
| **Воин** | 300 | 5 | Ускоренная базовая скорость перезарядки оружия на 50%[cite: 1]. |
| **Вампир** | 150 | 6 | Встроенный вампиризм: восстанавливает 10% здоровья от нанесенного урона[cite: 1]. |

### 2. Боевая система и Арсенал (Data-Driven Design)
Характеристики всего оружия полностью вынесены в файлы настроек `ScriptableObjects`[cite: 1]. Это позволяет настраивать баланс без изменения кода[cite: 1]. В игре доступны: **Пистолет, Дробовик, РПК/Автомат и Big Shot Gun**[cite: 1].
* **Честная перезарядка:** Реализована через асинхронные задержки (Корутины C#), не блокирующие игровой процесс[cite: 1].
* **Расчет баллистики:** Система учитывает разброс пуль (Spread Angle), количество дробинок в выстреле и пробитие врагов навылет[cite: 1].

### 3. Модульный ИИ врагов (Enemy AI)
Все противники управляются единым модульным скриптом `EnemyAI.cs`, меняющим логику на основе перечислений (Enum)[cite: 1]:
* **Обычный (Standard):** Преследование игрока с физическим обходом препятствий[cite: 1].
* **Камикадзе (Kamikaze):** Сближение на высокую скорость и взрыв по площади[cite: 1].
* **Снайпер (Sniper):** Удержание дистанции и прицеливание лазерным лучом (`LineRenderer`)[cite: 1].
* **Слайм (Slime):** Разделяется на два меньших слайма при уничтожении[cite: 1].
* **HookBoss:** Босс, использующий притягивание игрока крюком и спавн динамических бомб[cite: 1].

### 4. Внутриигровой магазин (Shop System)
Между волнами игрок может потратить заработанную валюту на улучшение характеристик в реальном времени[cite: 1]. С каждой покупкой стоимость возрастает[cite: 1]:
* Модификаторы: `+33 HP`, `+5 Урон`, `-10% Время перезарядки`, `Пробивание (+1 враг)`[cite: 1].

## 🛠 Технологический стек

* **Игровой движок:** Unity 2022.3 LTS (2D Tools, Physics2D, Tilemap, AudioMixer)[cite: 1].
* **Язык программирования:** C# (ООП, Паттерн Singleton, Coroutines, Свойства, Наследование от MonoBehaviour)[cite: 1].
* **Пользовательский интерфейс:** Unity UI (uGUI), TextMeshPro[cite: 1].
* **Сохранение данных:** Кроссплатформенная система `PlayerPrefs`[cite: 1].

## 🕹 Управление (Mobile & Unity Editor)

* **Перемещение:** Виртуальный экранный джойстик (Левая часть экрана)[cite: 1].

## 📦 Как скачать и запустить игру (APK)

В репозитории не хранятся тяжелые исполняемые файлы, чтобы не перегружать историю изменений Git[cite: 1]. Все готовые сборки распределены по версиям:



1. Перейдите в раздел **[Releases](https://github.com/твой_никнейм/твой_репозиторий/releases)** в правой части страницы.
2. Найдите актуальный релиз (например, `v1.0.0`).
3. Скачайте нужный файл сборки в зависимости от предпочтений:
   * `TopDown_v1.0_Normal.apk` — стандартная версия игры.
   * `TopDown_v1.0_Hardcore.apk` — версия повышенной сложности для тестирования баланса.
4. Перенесите файл на Android-устройство и установите (разрешив установку из неизвестных источников).
